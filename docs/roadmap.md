# SelfStudy 2.0 路线图

## 1. 内容合同（当前）

- 《碰撞与π》知识拼图共 139 个节点：A=27、B=30、C=46、D=36。
- A 板块有 20 个承载题目的二级节点，共 140 道客观题。
- 题量按知识重要性分配，题库包含 13 个场景题组和 8 道计算题。
- 建立客观题 Schema、生成器和测试

## 2. 作者工具

- 节点与题目联动筛选
- 修改记录、版本比较和审核状态
- 后续生成 B/C/D 题库

## 3. 学生答题运行时

- 只下发题干与作答字段，隔离标准答案和解析
- 正确/错误判定、多空容差与进度保存
- 答对后的下一题或追问选择
- 答错后的追问 Agent 路由

## 4. 错题追问 Agent

- 自我纠错对话协议
- 变式验证与退出条件
- 权益校验接口，但不在题库中保存付费状态

## 5. 账号与支付

- 用户、课程进度和服务权益
- 订阅或按次方案
- 隐私、未成年人和退款规则

## 6. 云部署

- 本地流程稳定后再选择服务器或小程序载体
- 内容存储、转码和 AI 服务可分别使用云服务
