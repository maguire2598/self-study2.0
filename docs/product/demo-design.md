# 本地学习 Demo：界面设计

关联：[前后端与数据库设计](../superpowers/specs/2026-09-13-local-learning-demo-design.md)。

## 方向

安静、严谨、可修正。以物理练习册为参考：纸色背景承载阅读，墨色承载题干，森林绿只标记当前学习位置和主要动作。不是展示型首页；打开就能进入一题，先看场景，再作答，再检查自己的思路。

单一实现方式：原生 HTML、JavaScript 和普通 CSS 自定义属性；无外部字体、组件库或运行时依赖。

## 视觉约定

- 画布 `oklch(96% 0.012 85)`，阅读面 `oklch(99% 0.006 85)`，侧栏 `oklch(92% 0.012 85)`。
- 主文字 `oklch(27% 0.018 155)`，次文字 `oklch(45% 0.018 155)`，主要动作 `oklch(39% 0.07 155)`。
- 中文标题使用系统宋体（Songti SC / SimSun），正文使用 Segoe UI / Microsoft YaHei / PingFang SC；避免为小型本地演示下载大体积字库。中文不收紧字距，阅读行高 1.75。
- 间距按 4、8、12、16、24、32px；圆角按 4、8、12px。布局用分区和留白，不把每条内容都装进卡片。
- 选项具有明确勾选标记；键盘焦点可见；按钮至少 40px 高。仅使用短促的 opacity/transform 交互过渡，并支持减少动态效果。

## 学生端

桌面：左侧课程板块和知识点目录，中间题目及配图，旁侧或下方显示本地进度。手机：目录改为紧凑的选择控件，题干、图像、选项纵向排列；375px 和320px检查横向溢出。

顺序保持 A 观察、B 方程、C 图像、D 待定。筛选器明确标注题型、节点和结果数量，不把空结果当作加载失败。题目可前后切换，重新打开可恢复最近作答位置。

C 的图像是作答内容，不是装饰。使用已有验证的 SVG；题干图、选项图、连续事件图均保持原始比例，提供放大入口；选项的替代文本只标记选项和图号，不透露正确性。

错误反馈只说需要检查，不显示正确选项或解析。追问面板明确标注“演示引导，非 AI”，有轮次上限，可重试或暂时跳过，不作学习能力或心理状态诊断。

没有可播放视频时如实说明，不做无效播放按钮。D 板块保留目录和待定说明，不自动生成题目。

## 作者端

独立页面和本地令牌登录。未登录不下载任何作者题目数据；登录后支持板块、节点、题型筛选和分页，可查看标准答案、解析及启停状态。启停带 revision 校验，冲突时明确提示刷新，不覆盖另一窗口的更新。

全题编辑继续使用原有作者工具；本轮作者 demo 只实现审核与启停。作者页能返回学习页，也能退出登录。

## 验收

检查加载、失败、无结果、D 待定；三类题目作答与进度持久化；错误后不泄露答案；C 各类图像；作者认证、启停与退出；桌面和窄屏的真实浏览器截图。隐私说明限定本机记录，本地 demo 不宣称已具备云账号、付费或生产级 AI 服务。
