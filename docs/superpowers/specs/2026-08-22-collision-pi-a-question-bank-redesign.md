# 《碰撞与 π》A 版节点与题库重构设计

**日期：** 2026-08-22  
**状态：** 已完成对话设计，等待文档复核  
**范围：** A 板块知识节点、客观题源数据、题库生成器、作者筛选器和相关合同

## 目标

A 版从统一套用六道题的模板题库，改为按知识重要性分配题量的场景题库。节点合并后，一级节点负责阶段导航，二级节点负责知识索引和题目归属。题干不再复述小节标题，重点内容通过共享初始条件的连续题组反复练习。

本轮交付包含 27 个 A 节点和 140 道客观题。计算题、斜面和弹簧组合情景仍属于 A 版的观察、判断与少量计算，不替代 B 板块对动量、动能和碰撞方程的系统讲解。

## 不在本轮范围内

- 不开发学生答题运行时、账号、支付或云部署。
- 不生成状态观察题。
- 不改变答错后的产品策略，学生端仍不得直接获得答案或解析。
- 不为旧 A 节点保留运行时别名。当前没有学生学习记录，旧编号只保留在迁移表中。
- 不照搬现成高中物理题目。题目采用高中物理的条件表达和设问节奏，内容保持原创。

## 题源与生成流程

`knowledge-puzzle.json` 继续作为节点的唯一来源。新增 `content/courses/collision-pi/question-source-a.json`，保存题目内容规格，不再把内容事实和通用模板写在 Python 脚本中。

题源分为三部分：

- `node_quotas` 保存二级节点的固定题量。
- `scenarios` 保存共享初始条件的场景题组。每个场景包含完整情景、变量、条件和若干独立设问。
- `standalone_questions` 保存基础覆盖短题，主要用于术语、计数口径和边界判断。

生成器读取知识拼图和题源，展开每道题的完整题干，生成稳定 ID，排列选项，检查答案结构，再写入 `question-bank-a.json`。作者筛选器从正式题库构建。知识拼图 Markdown 由 JSON 重新生成，避免 JSON 和目录文档分开维护。

## 场景题组

场景题组复用初始条件，但每道最终题目必须自包含。学生不需要看见上一道题，也不能依赖上一题的作答结果。

每道题增加以下作者端字段：

- `question_style`：`scenario`、`calculation` 或 `concise`。
- `scenario_id`：同一场景题组共享的稳定编号；独立短题可省略。
- `event_stage`：`initial`、`after_first_collision`、`after_wall_collision`、`after_second_collision`、`terminal`、`special_case` 或 `extension_stage`。
- `variant_axis`：本题改变的条件，如 `mass_ratio`、`initial_velocity`、`friction`、`elasticity`、`incline` 或 `spring`。

A3 和 A4 的 72 道题使用 10 个核心场景题组；A7 使用 3 个组合场景题组。一个典型题组从同一组初始条件出发，依次考查是否相撞、第一次碰撞后的速度、动量与动能变化、撞墙后的方向、能否再次追上、第二次碰撞后的状态，以及等质量或大质量比的特殊情况。

等质量、完全弹性、小物块初始静止时，大物块第一次碰撞后停下，小物块取得大物块原速度。题目把它写成等质量特殊情形，不称为大质量比极限。`M≫m` 的题目只考查速度分配趋势和碰撞次数趋势。

## 题干与选项风格

题目采用高中物理习题常见的表达顺序：给出对象、方向约定和必要条件，随后询问一个明确结果。情景题主要考查速度大小与方向、是否相撞、是否还能追上、单体动量变化、单体动能变化和系统守恒。干扰项对应可解释的常见错误，如忽略速度方向、混淆单体和系统、跨阶段误用动量守恒、把完全弹性理解为单体动能不变。

禁止使用以下自动套话：

- `关于“节点标题”，下列哪项表述最准确？`
- `判断“节点标题”时应采用哪项依据？`
- `下列哪项最符合“节点标题”的操作约定或适用边界？`

节点标题可以作为作者端标签，题干只能在物理语义自然需要时使用其中的词语。条件组合采用代表性覆盖，不做摩擦、质量、弹性和初速度的完整笛卡尔积。

## 计算题

题库固定包含 8 道 `question_style=calculation` 的客观题，分布在 A3.2、A3.3、A3.5、A7.1 和 A7.2。题型仍使用单选、多选或多空填空，不增加主观题型。

计算题覆盖：

- 等质量一维完全弹性碰撞的速度交换。
- 不等质量情况下联立动量守恒和动能守恒求碰后速度。
- 根据速度符号判断碰后方向。
- 计算单个物块的动量变化或动能变化。
- 斜面运动与碰撞的分段计算。
- 碰撞后压缩弹簧的最大压缩量或能量分配。

题源中的计算场景保存质量、初速度和预期结果。测试用独立公式重新计算预期值，不只比较题源里重复抄写的答案。

## 斜面与弹簧拓展

斜面和弹簧题采用组合情景，不把连续过程笼统称为碰撞。每题明确时间段和研究系统。

斜面题区分物块沿斜面运动、短时碰撞和碰后继续运动。若外力冲量不能忽略，题目不得直接使用所选系统的动量守恒。弹簧题区分短时碰撞和随后压缩弹簧的过程，动量守恒与机械能守恒分别按系统边界和阶段判断。

A7 只承担迁移和边界检查。需要完整推导的斜面动力学、弹簧振动或恢复系数仍留给后续课程内容。

## 内容来源与物理核对

视频仍是课程主来源。A3 计算、A7 斜面和弹簧拓展需要用权威高中物理资料或大学基础力学资料交叉核对。题源在场景层保存 `source_refs`，记录核对来源；若外部资料与视频表述冲突，在作者备注中说明差异，不直接否定视频。

## 题库合同

题库版本升为 `2.0.0`。删除统一的 `distribution_per_node`，改为 `question_count_by_node`。Schema 将题目总数固定为 140，并要求每题具有 `question_style`。场景字段保留在作者端题库中，未来学生端下发时仍需执行答案与作者元数据隔离。

题库继续遵守以下规则：

- `assessment_kind` 固定为 `objective`。
- 状态观察模块保持关闭。
- 答错后不显示答案或解析，继续路由至错题追问 Agent。
- 单选题恰有一个正确选项，多选题恰有两个正确选项。
- 多空填空的每个空至少有一个可接受答案。

## 作者筛选器

筛选器取消任何 192 题或每节点 6 题的假设。知识点下拉框显示 20 个承载题目的二级节点。题卡显示 `question_style`、`scenario_id` 和 `event_stage`，并增加场景题组筛选，便于连续审阅同一初始条件下的多道题。

本地草稿继续按题库版本隔离。题库升为 `2.0.0` 后，旧版 `1.0.0` 草稿不会自动载入，避免旧 `node_id` 混入新题库。

## 验收规则

自动测试需要覆盖以下合同：

- 全课程共 139 个节点，分布为 A 27、B 30、C 46、D 36。
- A 恰有 7 个一级节点和 20 个二级节点。
- 题库恰有 140 题，且只引用 A 的二级节点。
- 每个二级节点的题量与表中配额一致；各节点题量不再相同。
- `scenario` 与 `calculation` 合计至少占题库的 65%。
- 计算题恰有 8 道。
- A3 和 A4 恰有 10 个核心场景题组，A7 恰有 3 个组合场景题组。
- 题目 ID 和题干全局唯一，禁止套话不出现。
- 每道场景题的最终题干自包含，不引用上一题或上一问的答案。
- 计算场景的质量、初速度、碰后速度、动量变化和动能变化通过独立公式校验。
- 题库、知识拼图 Markdown 和筛选器可以重复构建，构建后工作区无额外差异。
- 浏览器中可以按节点、题型、关键词和 `scenario_id` 筛选；不均匀题量、空结果和节点切换正常。
