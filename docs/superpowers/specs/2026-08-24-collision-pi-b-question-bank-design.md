# 《碰撞与π》B 板块知识节点与题库设计

## 1. 目标

在已验收的 A 板块题库方法上，完成 B 板块的知识节点重排、客观题内容建模、确定性生成和作者端筛选。B 板块承担“从物理量和守恒条件，走到方程建立、联立求解与连续碰撞递推”的方法训练，因此题量和计算密度高于 A，但仍以具体物理情境为主，不把题库写成抽象概念辨析清单。

本设计只生成有正确答案的客观知识题。状态观察题继续关闭；答错后不直接向学生端下发标准答案或解析。

## 2. 设计原则

1. 知识顺序遵循“记录物理量 → 选择系统 → 建立方程 → 求解检验 → 连成事件链”。
2. 重复节点合并，重要方法通过不同条件和不同问法反复训练，次要拓展只做必要覆盖。
3. 一个完整场景可以连续考查碰前总量、列式、碰后速度、动量变化、动能分配、后续事件和极限状态；每道题必须独立包含必要条件，不能依赖上一题答案。
4. 题干不出现生硬的节点小标题，不使用“关于某知识点”一类模板句。
5. 所有涉及方向、守恒或分段过程的题目明确正方向、研究系统和时间区间。
6. 干扰项来自真实错误：漏负号、混淆单体量与系统总量、跨系统或跨阶段套守恒、误用平凡解、舍错根、忽略接近条件。
7. 解析不依赖选项位置；生成器轮换选项后，解析仍须直接指明物理量、数值或关系。
8. 视频是课程主来源，外部权威教材用于交叉核对方程、边界条件和拓展内容；出现冲突时记录来源，不武断覆盖视频。

### 4.4 计算夹具

32 道计算题必须各自引用一个可执行夹具，至少覆盖：

- 带符号动量、动量变化和冲量。
- 碰前后总动能及非弹性碰撞能量损失。
- 任意质量和任意初速度的一维弹性碰撞。
- 相对速度关系和恢复系数。
- 等质量、1:3、3:1、大质量比和极限趋势。
- 一次碰撞后撞墙、二次碰撞和终止状态。

夹具验证必须独立复算动量、动能、相对速度和答案字段，不能使用题目解析中的结果作为预期值来源。

## 5. 内容写作规则

1. 情景优先使用滑块、小车、光滑轨道、固定墙、测速器、力传感器和实验记录表。
2. 计算数值优先选择能得到整数或简单分数的质量和速度；综合题可以使用字母量，但不得把代数复杂度当作难度。
3. 一题只承担一个主要判断；多选题可考同一场景下彼此关联的两条结论。
4. 场景上下文可复用，但每个 `ask` 与上下文拼接后必须自洽完整。
5. 不使用“上一题”“沿用前问结果”“如前所述”等依赖措辞。
6. 不使用颜色、编号、字体、时间停止、质量变为零等无关或幻想式干扰项。
7. 方向、系统或阶段是答案关键时，题干必须显式给出；只求速率、能量或压缩量等非负标量时不强制声明正方向。
8. 对固定墙反弹，必须区分“滑块系统动量不守恒”和“把墙、地球纳入足够封闭系统后的总动量守恒”。
9. 对动能守恒，必须限定完全弹性碰撞和所选系统；总动量守恒不能推出总动能守恒。
10. 对方程解，必须区分未发生速度交换的平凡解与接触碰撞后的物理解。
