# 《碰撞与π》C 板块图文题库设计

**日期：** 2026-08-26

**状态：** 对话设计已确认，等待文档复核

**实施基线：** `codex/collision-pi-a-redesign` 的 `3d10ee2`

**范围：** C 板块客观题、声明式物理图、确定性 SVG、正式题库、作者筛选器和验证合同

## 目标

C 板块把一维碰撞状态转成几何对象。学生需要在原始速度坐标、质量加权速度坐标和选修的位置坐标之间切换，读懂状态点、能量椭圆、能量圆、动量直线、碰撞弦、墙反射、安全区域、等角跳跃和楔形展开。

本轮制作 180 道有正确答案的客观题。C1-C8 为 168 道核心题，C9 为 12 道选修题。题目使用原创的程序生成 SVG，不复制教材或视频截图。自由绘图、拖拽作图和需要人工评分的开放题不在本轮范围内。

题库继续遵守项目边界：状态观察题保持关闭；标准答案和解析只供作者端与判题端使用；学生答错后不直接显示答案或解析；题目结果不得用于心理诊断。

## 方案选择

采用声明式图像源、确定性 SVG 和图像清单。每张图先保存坐标体系、物理参数、点线关系和无障碍文字，再由固定模板生成 SVG。数学测试检查声明数据，浏览器验收检查最终渲染。

不采用人工逐张绘制 SVG。人工图改动快，但坐标、斜率和标签容易漂移，也无法可靠批量验证。不采用运行时 Canvas 或交互作图，当前项目尚无学生运行时，这条路线会提前引入交互状态和主观判分问题。最小方案只做少量固定图片，无法覆盖质量比、点位和错误图变式，因此不作为交付目标。

## 节点顺序

现有 C 板块保持 9 个一级阶段、37 个承载题目的二级节点，共 46 个节点，不迁移 `node_id`。顺序固定为：

1. C1 速度相空间与状态点。
2. C2 动能守恒的几何图像。
3. C3 质量加权坐标缩放。
4. C4 动量直线与碰撞弦。
5. C5 墙壁碰撞的几何反射。
6. C6 完整状态演化与终止区域。
7. C7 等角跳跃与圆弧计数。
8. C8 图像元素的物理意义总表。
9. C9 光线反射法，选修。

一级节点只组织学习阶段，不直接挂题。题库、题源、图像、筛选器和学习记录只引用二级 `node_id`。

## 图像呈现合同

每题必须具有一个 `presentation_mode`：

| 模式 | 合同 | 题数 |
| --- | --- | ---: |
| `text_only` | 不引用图像 | 60 |
| `stem_figure` | 题干引用一张图 | 72 |
| `option_figures` | 四个选项各引用一张图 | 24 |
| `figure_sequence` | 题干引用 2 至 4 张有顺序的图 | 24 |

合计 120 道配图题。每个核心二级节点至少有两道配图题。`option_figures` 的文字、图片引用和正确答案必须作为同一个选项对象轮换。`figure_sequence` 使用稳定顺序，不依赖文件名自然排序。

配图题重点考查读图、图式转换、补全状态、错误诊断和图像排序。干扰图来自真实错误：坐标轴对调、漏乘质量平方根、斜率倒数错误、把状态轨迹当成空间路径、反射轴错误、混淆 `θ` 与 `2θ`、安全区落在错误象限。

## 坐标体系合同

每张图必须声明 `coordinate_system`：

- `velocity_raw`：横纵轴记录原始速度分量 `(v_M,v_m)`。
- `velocity_weighted`：横纵轴记录 `(√M·v_M,√m·v_m)`。
- `position_weighted`：C9 使用的质量加权位置坐标。

坐标体系进入图像 ID、图注、无障碍文字和数学测试。不同坐标体系不得共用未标明含义的 `x`、`y`。原始速度坐标中的动能曲线是椭圆，质量加权速度坐标中的动能曲线是圆。安全边界、动量线斜率和点坐标必须按当前坐标体系推导，不能把某个特例中的 `y=x` 当成通用结论。

- `content/courses/collision-pi/question-bank-c.json`

C 题源延续 A/B 的 `node_quotas`、`source_catalog`、`calculation_fixtures`、`scenarios` 和 `standalone_questions`。C 题增加：

- `curriculum_scope`：`core` 或 `elective`。
- `presentation_mode`：四种图像呈现方式之一。
- `figure_refs`：题干图像或图像序列。
- 选项可带 `figure_ref`。
- `diagram_focus`：本题主要检查的图像关系。

正式 bank 的 C 条件分支要求 180 题、37 个配额键、168 道核心题和 12 道选修题。C bank 顶层保存 `diagram_manifest_fingerprint`，题库 `content_fingerprint` 必须覆盖这个值。图像变化会使旧 C 草稿失效，避免旧图和新题静默组合。

A/B 正式题库不增加必填图像字段，题目数组和内容指纹必须保持不变。共享生成器只扩展对 C 可选图像数据的透传和校验，不复制 A/B 的展开逻辑。

## 作者筛选器

作者工具从 A/B 扩展为 A/B/C。现有筛选顺序保留为板块、知识点、题型、场景和关键词，C 板块再显示课程层级与配图方式筛选。

题卡在题干前显示图像或图像序列。图像选项和文字选项共用答案控件。作者可查看图像 ID、坐标体系、图注和无障碍文字，但不在 HTML 中直接编辑 SVG 路径。图像参数在 `diagram-source-c.json` 中维护，避免题卡承担图形编辑器职责。

缺失图像、未知图像 ID、manifest 指纹不匹配或加载失败时，作者端必须显示明确错误，不能静默空白。A、B、C 草稿继续按板块隔离，并使用当前题库内容指纹验证。

## 内容写作规则

1. 题干不生硬复述节点标题，不使用“关于某知识点”的模板句。
2. 每道图像题明确图中坐标体系，必要时给出质量比和方向约定。
3. 状态点表示一对速度，不表示两个物块的真实位置。
4. 换刻度只改变表示，不改变原物理状态。
5. 物块碰撞对应同一动量线与能量曲线的两个交点，墙碰撞对应小物块速度变号。
6. 每一次几何跳点只有在能对应一次真实碰撞时才能计数。
7. C7 题明确区分弦方向角、圆周角、圆心角、`θ` 和 `2θ`。
8. C9 始终标为选修，不把位置空间楔形与速度相空间混成同一个坐标图。
9. 解析直接点名坐标、公式、点或关系，不依赖选项位置和颜色。
10. 图像题仍是一题一个主要判断，多选题只组合紧密相关的结论。

- 椭圆点满足原始速度坐标中的能量方程。

7. 扩展作者工具为 A/B/C，加入课程层级、呈现方式和图像预览。
8. 逐读 180 道题，逐图核对 36 个实例，完成双轮构建、全量测试、Schema 和浏览器验收。

## 风险边界

最脆弱的前提是坐标体系始终明确。原始速度坐标、加权速度坐标和位置坐标一旦混用，安全区、动量线斜率和反射关系都会出错。强制 `coordinate_system`、声明式参数和独立数学测试共同保护这条边界。

图像数量不是主要风险，图文关系漂移才是风险。manifest 指纹进入 C bank 内容指纹，任何图像变更都会让旧草稿失效。图像源和题源通过稳定 ID 连接，不通过文件顺序或题干文字猜测关联。
