# 城市比喻体系

> 最后更新：2026-07-11
> 来源：[心灵自然哲学](../docs/theory/mind-natural-philosophy.md)、galgame-teacher.md

## 体系总览

城市比喻将自主学习系统映射为一座城市。六个维度对应六个城区/设施，学生是市长。

```
                       🏛️ 市政中心（SLF 自我管理）
                     市长办公——精力预算、情绪调节、计划执行
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
   ⚡ 发电站              🔬 研究院            🏟️ 竞技场
  ATT 注意力            REF 内省反思          EXM 考试表现
  思维能量               观测与日志            实践验证
        │                     │                     │
        └─────────────────────┼─────────────────────┘
                              │
              ┌───────────────┼───────────────┐
              │                               │
         🔧 工厂区                        📦 仓储区
        MTH 方法应用                    KNW 知识管理
        机器选型、调试                 进货、分类、调取
```

## 六城区详解

### ⚡ 发电站（ATT 注意力）

- **比喻核心**：注意力 = 电力。专注时长为发电量，走神为断电。
- **城市叙事**：发电站稳定供电是城市运转的前提。功率不稳→全城灯光忽明忽暗。
- **学生自评模板**："发电站现在——满功率 / 半功率 / 红灯闪烁？"
- **禁止比喻**："水力""风力""太阳能"——破坏了"电力"的统一性

### 🔬 研究院（REF 内省反思）

- **比喻核心**：内省 = 观测塔上的研究员，记录城市运行日志。
- **城市叙事**：研究院监测全城，记录日志，发现"哪座桥该修了"。
- **学生自评模板**："翻开研究院的日志——你今天观测到了什么？"
- **注意**：研究院只观测，不生产（不"制造答案"）

### 📦 仓储区（KNW 知识管理）

- **比喻核心**：知识节点 = 货物。入库 = 学到新知识，调取 = 回忆，盘点 = 自评。
- **城市叙事**：新货物（知识）不断入库，旧货物需要定期盘点和整理。
- **学生自评模板**："仓库里新增了哪些货？有哪些货你找不到了？"
- **禁止比喻**："知识河流""知识大树"——破坏了仓储隐喻

### 🔧 工厂区（MTH 方法应用）

- **比喻核心**：方法 = 机器。选型 = 选择方法，调试 = 调整参数，升级 = 方法改进。
- **城市叙事**：工厂区是城市的"生产力中心"。新机器（方法）安装后会试运行。
- **学生自评模板**："工厂里现在有哪些机器在运转？新装了什么设备？"
- **禁止比喻**："方法种子""方法道路"——破坏了工厂隐喻

### 🏛️ 市政中心（SLF 自我管理）

- **比喻核心**：自我 = 市长。调度各部门资源，做预算，应对危机。
- **城市叙事**：市长办公的地方。精力预测、情绪调节、学逸平衡都在这里决策。
- **学生自评模板**："市长，今天的预算（精力）怎么分配？"
- **注意**：市长不亲自解题（那是工厂区的事），不亲自记忆（那是仓储区的事）

### 🏟️ 竞技场（EXM 考试表现）

- **比喻核心**：考试 = 竞技比赛。训练 = 学习过程，排名 = 成绩。
- **城市叙事**：实战检验一切——发电站、研究院、工厂区、仓储区的能力最终在这里接受检验。
- **注意**：竞技场是"效果层"不是"能力层"——低分不代表五个维度都差

## 比喻连接规则

```
MUST: 电力走电线（能量传输）
MUST: 逻辑走道路（推理连接）
MUST: 知识是货物（可存储、运输、盘点）
MUST: 方法是机器（可拆解、组装、升级）

禁止跨体系混用：
  ❌ "发电站的水管"（电力不走水管）
  ❌ "仓库的机床"（仓库存储，工厂加工）
  ❌ "工厂区的观察日志"（工厂生产，研究院观测）
```

## 天气系统（情绪映射）

| 天气 | 情绪状态 | 触发条件 |
|:---|:---|:---|
| ☀️ 晴 | 平静、积极 | 默认状态 |
| ☁️ 阴 | 疲倦、低能量 | 连续长时间学习后 |
| 🌫️ 雾 | 迷茫、不确定 | 连续选C/D时 |
| ⚡ 雷雨 | 烦躁、焦虑 | 频繁走神或改选时 |
| 🌙 星 | 沉思、内省 | 阶段5（观测塔） |
| 🌈 彩虹 | 顿悟、突破 | 从卡点到理解的转折 |
