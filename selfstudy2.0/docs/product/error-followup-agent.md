# 错题追问 Agent 产品边界

## 定位

错题追问 Agent 是独立付费服务。它不直接公布答案，而是通过追问帮助学习者定位缺失的知识、条件或推理步骤，最终由学习者自己修正答案。

## 运行规则

| 作答结果 | 学生端动作 |
|:---|:---|
| 正确 | 可进入下一题，也可主动打开错题追问 Agent 继续检查理解 |
| 错误 | 不展示标准答案与作者解析；进入错题追问 Agent |

题库只保存以下交付策略，不保存订阅状态：

```json
{
  "reveal_answer_after_wrong": false,
  "wrong_answer_action": "error_followup_agent",
  "correct_answer_actions": ["next_question", "error_followup_agent"]
}
```

## Agent 目标

1. 识别错误对应的知识节点与可能缺口。
2. 让学生说明已有依据，不先给结论。
3. 通过更小的问题检查概念、条件、符号和步骤。
4. 引导学生修改原答案并解释修改理由。
5. 用一道等价或轻微变式题验证是否真正修正。

## 明确禁止

- 不在第一轮追问中透露正确选项。
- 不把答错解释为智力、人格或心理问题。
- 不用无限追问迫使学生付费或延长会话。
- 不让题库数据承担订阅、支付和用户权益判断。

## 后续单独设计

- 订阅资格和免费体验次数
- Agent 会话协议与提示词
- 放弃、跳过和教师/监护人策略
- 最长追问轮次和成本控制
- 答案泄露防护、申诉和内容安全
- 学习证据与隐私保存规则
