# 本轮产品决策

## 课程生产

- 一个教学视频原则上对应一门课程。
- 长视频可以增加学习阶段；学习进度必须可保存。
- AI 识别视频知识框架和知识点数量，再按核心教学框架划分阶段。
- 视频是主来源，同时自动查阅权威资料；发生冲突时标记来源，不直接否定视频。
- 外部资料可以用于交叉核验和制作拓展内容。

## 学习路径

- 原则上建议先完整观看视频，再进入深化学习。
- 学生可以按自身情况改变顺序；未来通过评估推荐路径，不强制单一路线。
- 知识学习与心理/学习状态观察是独立模块，用户可以关闭状态观察。
- 状态观察不得等同心理诊断；当前版本暂不生成状态评估题。

## 《碰撞与π》知识拼图

- 顶层采用 A/B/C/D 四板块。
- A：碰撞现象、初始状态、事件链、结束条件和π规律观察。
- B：动量、动能、碰撞模型与方程求解。
- C：速度相空间、质量加权缩放、几何计数；C9 光线反射法为选修。
- D：从质量比和固定转角计算碰撞次数，解释π及其位数关系，并处理近似和整数边界。
- 内部保存知识图谱，学生端使用可读目录树；重复内容用引用关系而非复制节点。

## 题目规则

- 旧版题目约束作废；客观题均有正确答案。
- 三种题型：单选、多选、多空填空。
- 每个知识节点 6 题：3 单选、2 多选、1 多空填空。
- A 板块 32 个节点，共 192 题。
- 状态评估题不混入客观题，当前暂缓。

## 错题追问服务

- 作为后续付费服务独立开发。
- 答对后可选择下一题或主动使用错题追问 Agent。
- 答错后不展示答案和解析，未来学生运行时要求进入 Agent 引导流程。
- Agent 的目标是帮助学生定位知识漏洞、自我纠错并自行得到正确答案。
