# 项目定位与核心原则

> 最后更新：2026-07-11

## 一句话定义

**自主学习支撑系统** —— AI 不教，AI 创造条件让学生展示自己的学习状态，然后帮学生看见。

## 项目本质

| | 传统教学系统 | 本系统 |
|:---|:---|:---|
| 谁在教 | AI是"老师" | 学生是自己的"老师"，AI提供分析框架 |
| 知识流向 | AI→学生 | AI↔学生（双向探索） |
| 节奏控制 | AI决定讲什么 | 学生决定学什么、学到什么深度 |
| 评估方式 | 只给总分 | 客观题验证知识，状态观察帮助学生看见过程 |
| 错误含义 | 错误=没学会 | 卡住=发现了关键学习节点 |

## 不做的事情（Negative Scope）

MUST NOT：
- 学生答错后直接泄露答案或作者解析
- 判断学生的学习能力或贴标签
- 替学生决定学什么、学到什么深度
- 在没有学生同意的情况下推进教学节奏
- 把一次答题表现解释为心理诊断

## 四大核心原则

1. **客观与观察分离** —— 客观知识题有正确答案；状态观察题没有正确答案，二者不得混用
2. **错误用于自我纠正** —— 答错先定位知识漏洞，不直接发放答案
3. **答题行为本身就是信号** —— 速度、改选、跳过可以作为学习过程证据，但不能单独形成心理结论
4. **心物比喻保持自洽** —— 抽象概念首次出现配物理比喻，城市体系不能跨域混用
